# Security policy

Please report security problems privately. Do not open a public issue or pull request.

- Email: security@shakewell.agency
- Or use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability").

Include the plugin version, what an attacker can do, and the steps to reproduce. We reply within two working days, agree a fix date with you, and credit you in the changelog unless you ask us not to.

Only the latest release is supported. Fixes are released as a normal update and noted in the changelog.
